# Настройка Яндекс.Диска

## Получение OAuth токена через собственное приложение (рекомендуется, полные права)

1. Зарегистрируйте приложение на https://oauth.yandex.ru/client/new

2. Укажите:
   - **Название:** "Log Sender" (любое)
   - **Режим:** Для доступа к API и отладки
   - **Доступы:** 
     - ✅ Яндекс.Диск (REST API) - **Чтение всего Диска**
     - ✅ Яндекс.Диск (REST API) - **Запись в любом месте**
     - ✅ Яндекс.Диск (REST API) - **Доступ к информации о Диске**

3. Нажмите "Создать приложение" и скопируйте **Client ID**

4. Откройте в браузере (замените YOUR_CLIENT_ID на ваш):
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=YOUR_CLIENT_ID
   ```

5. Разрешите доступ и скопируйте токен из адресной строки (после `access_token=`)


## Настройка в config.yaml

```yaml
yandex_disk:
  enabled: true
  oauth_token: "y0_AgAAAAA..."  # Ваш токен
  upload_path: "/logs"  # Путь на Яндекс.Диске
  delete_after_upload: false  # Удалять ли локальные файлы после загрузки
```

## Проверка токена

```bash
python3 test_yandex_disk.py
```

## Структура на Яндекс.Диске

После загрузки файлы будут доступны по пути:
```
Яндекс.Диск/
└── logs/
    ├── access.log-2026-02-04-1430.gz
    ├── error.log-2026-02-04-1430.gz
    └── ...
```

## Ограничения

- Максимальный размер файла: 50 ГБ
- Скорость загрузки зависит от вашего интернет-соединения
- Токен действителен 1 год, после чего нужно получить новый

## Безопасность

⚠️ **Важно:**
- Не публикуйте токен в открытых репозиториях
- Храните config.yaml в безопасном месте
- Используйте права доступа: `chmod 600 config.yaml`
- Токен дает полный доступ к Яндекс.Диску пользователя

## Отключение Яндекс.Диска

Чтобы отключить загрузку на Яндекс.Диск:

```yaml
yandex_disk:
  enabled: false
```

Или удалите секцию `yandex_disk` из конфига.
